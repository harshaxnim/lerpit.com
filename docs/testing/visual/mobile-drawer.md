# Mobile drawer

Sizes: 390×844 (phone), 768×1024 (tablet), 844×390 (phone landscape). Routes: every lesson with a stage.

- [ ] Closed: a slim tab on the right edge, the panel name written vertically between two ◀ arrows.
- [ ] The tab shimmers once when the chapter behind it changes.
- [ ] Opening slides the stage in; arrows turn to ▶; aria-expanded and the label say "Hide …".
- [ ] Open stage: tabs at the top, the panel filling the rest, caption at the foot, its own graph paper.
- [ ] Corner cards split the top edge; neither covers the other.
- [ ] Closing returns to the prose where it was.
- [ ] Rotating or resizing past 1180px returns to the side-by-side layout with the drawer state cleared.
- [ ] 844×390: the stage fits the short height; the caption does not cover the whole panel.
- [ ] No horizontal page scroll at any of the three sizes, open or closed.
- [ ] The L/P dev button stays small and does not cover the drawer tab.
