Editing in the browser

Write and arrange your lerpettes and collections on the page itself, with the real page as your preview. It works only on your machine, under npm run dev; readers never see any of it.

Start

  1. Run npm run dev and open any page.
  2. Press the pencil ✎ beside the L button, bottom right. It shows only in local view; public view (P) is the page as a reader gets it.
  3. The page goes into edit mode, and a bar appears at the foot of the window: EDITING Springs ● 2 unsaved⚙ SettingsSaveDone

What you can edit depends on the page: a lesson edits that lerpette, a collection page edits that collection, and the library is where you make new ones.

Writing a chapter

Click any chapter, or its ✎ Edit button. It opens in place:

  • Title and id ({#the-loop}). The id is the chapter's anchor and the name of its code folder.
  • Panels: click a chip to add or drop viewport2d, table and the rest. A chip marked · comes from the title, which every chapter inherits.
  • The text, in Markdown. The buttons add bold, italics, links, maths ($x$, $$…$$), a list, an image, or a code box.
  • Under it, the preview redraws as you type, exactly as the page will render it, maths and figures included.

The stage keeps running beside you. Esc closes a chapter; your changes stay until you save or leave.

Adding, moving, deleting

  • + Add a chapter here sits between the boxes. A new chapter's id follows its title until you type one.
  • ↑ ↓ in an open chapter move it. The trash button deletes it; you can Undo until you save. Its code folder is never deleted.
  • Renaming an id also renames its code/<id>/ folder and its caption when you save. The editor tells you before it does.

Images

Drop or paste an image into the text, or use image. It is saved beside mixtape.md (never over an existing file) and linked where your cursor was. Give it alt text: a lone image with alt text becomes a figure with a caption.

Settings

⚙ Settings slides in over the stage:

SettingWhat it does
StatusPublished: listed everywhere. Unlisted: the link works, but it is on no shelf. Draft: only on your machine.
Serve at /Makes this the landing page (published lerpettes only).
OrderIts place in the collection; the rest follow newest first.
BylineAuthor and date, the first line of the document.
CaptionsThe line under the panel, per chapter.
Code box idle textWhat a code box says before its first build.

The same sheet lists every problem the site finds, and lets you edit control.toml or mixtape.md as plain text. Comments you have written in control.toml are kept.

Collections

Get to a collection's editor from the library (Edit collection, beside Open collection), or press the pencil on the collection's own page. Edit its title and introduction in place. ⚙ Cards & settings holds:

  • Card style and palette. Every card on the page redraws as you click, so you can choose by looking. auto lets the site pick.
  • Lerpettes: each one's status and its order in the collection, without opening it.

A lesson's ⚙ Settings has a Collection group too, with the same card style and palette, and a link to the collection's own editor.

Making something new

  • A lerpette: in edit mode on a collection page or the library, click the dashed New lerpette card. Give it a title; the folder name (its URL) is filled in for you. It starts as a draft with one chapter and a ball on a spring on its stage, and opens in edit mode.
  • A collection: on the library, + New collection. Pick its card style and palette while watching a preview card.

Saving

Save or ⌘S writes to disk. Nothing is written until you do. Lines you didn't touch are written back exactly as they were, so your git diff shows only your changes.

  • Text-only changes save in place. Changes to panels, ids, order or settings reload the page, which comes back in edit mode where you were.
  • Unsaved work is also kept in this browser. If the tab closes, you'll be offered it back next time.
  • If the file changed on disk while you were editing (say you saved it in VS Code), the editor keeps your version on screen and asks on save: keep editing, overwrite with yours, or drop yours and reload.

Done leaves edit mode. If you have unsaved changes, it asks first.

Renaming or deleting a whole lerpette or collection folder is not in the editor. Do that in Finder or git.
